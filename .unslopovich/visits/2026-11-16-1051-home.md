## Findings and treatment

Critical:
- Original `app.py:344`: absent geolocation was labeled “Local/Private Network,” including disabled or failed lookups. Browser fallback now says “Unavailable (local address, disabled, or lookup failed).”

Noticeable:
- Original `app.py:314`: “public IP” was asserted even for direct private addresses. Now “Client address seen by this server.”
- Original `app.py:90–225`: several rounded, tinted panels, centered content, and repeated padding slowed scanning. Kept the existing palette and font families, removed inner panels and shadows, aligned labels and values, and reduced desktop row height.
- Original `app.py:140`: unrestricted mid-group IPv6 breaking. Main address now offers break opportunities after colons; emergency wrapping still prevents overflow at enlarged text sizes.
- Original `app.py:308`: emoji-only theme button, broad color transitions, hover growth, and storage access that could throw. Replaced the emoji with a visible mode label and accessible action name; added focus and pressed states; removed motion; guarded storage access and applied the preference before rendering content.
- Original `app.py:377`: descriptions and commands shared wrapped paragraphs. Commands now have independent keyboard-scrollable lines with readable descriptions.

Worth keeping: Server-rendered content, direct access to the IP, all existing detail fields, manual/system theme choice, GitHub link, version information, curl URLs, and native selection.
